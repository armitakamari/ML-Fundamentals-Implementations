# ML Algorithms From Scratch

Core Machine Learning algorithms implemented **from scratch** (NumPy) and benchmarked against **Scikit-Learn** baselines.

## Notebooks

| # | Notebook | Key Focus |
|---|----------|-----------|
| 01 | [KNN from Scratch](./01_knn_from_scratch.ipynb) | Sklearn-compatible estimator, Euclidean/Manhattan metrics, GridSearchCV pipeline |
| 02 | [Logistic Regression from Scratch](./02_logistic_regression_from_scratch.ipynb) | Batch GD, weighted cross-entropy, SMOTE — churn prediction |
| 03 | [Linear Regression — Gradient Descent](./03_linear_regression_gradient_descent.ipynb) | Vectorized BGD, weight convergence tracking, MSE/RMSE/MAE |
| 04 | [K-Means & DBSCAN Clustering](./04_kmeans_dbscan_clustering.ipynb) | Elbow & silhouette analysis, k-NN distance graph for ε, PCA visualization |

## Tech Stack

`Python` · `NumPy` · `Pandas` · `Scikit-Learn` · `Imbalanced-Learn` · `Matplotlib` · `Seaborn`
